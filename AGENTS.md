## Agent skills

### Issue tracker

Las especificaciones y tareas se gestionan mediante GitHub Issues. Consulta `docs/agents/issue-tracker.md`.

### Triage labels

Se utilizan las cinco etiquetas predeterminadas de triage. Consulta `docs/agents/triage-labels.md`.

### Domain docs

El repositorio utiliza una estructura de dominio single-context. Consulta `docs/agents/domain.md`.

### Continuidad

Al retomar la implementación o cambiar de chat/modelo, consulta `HANDOFF.md` para conocer el último ticket terminado, el próximo trabajo, la verificación y los límites vigentes. Actualízalo al cerrar cada ticket o cambiar el estado operativo.
