# Domain Docs

## Before exploring, read these

- Read `CONTEXT.md` at the repository root.
- Read ADRs under `docs/adr/` that affect the area being changed.
- If either location does not exist, proceed silently.

## File structure

This is a single-context repository. It uses one `CONTEXT.md` at the root and stores architectural decisions under `docs/adr/`.

## Use the glossary vocabulary

Use terms as defined in `CONTEXT.md` in issues, tests, documentation and implementation. Avoid synonyms that the glossary explicitly rejects.

## Flag ADR conflicts

Surface any contradiction with an existing ADR explicitly instead of overriding it silently.
